## Selected Experiments

- **Blackbody Radiation** — selected because it includes a report, Excel analysis, extracted figures, and raw text data; it demonstrates logarithmic transforms, least-squares fitting, and nonlinear spectral fitting.
- **Photoelectric Effect** — selected because it includes a complete report and Excel workbook with stopping-voltage fits and a Planck-constant estimate.
- **Electron Diffraction and Crystal Structure** — selected because it includes a complete report, Excel analysis, and clear comparison between measured and expected lattice spacings.
- **Hydrogen/Deuterium Spectroscopy** — selected because it includes a complete report and Excel workbook with Balmer-series and isotope-shift analysis.
- **Hall Effect and Semiconductor Conductivity** — selected because it directly supports semiconductor/electronic-materials analysis and includes temperature-dependent conductivity fitting.
- **High-Temperature Superconductivity** — selected because it directly supports superconducting behavior, transition-temperature analysis, and experimental interpretation.
- **Radioactivity** — selected because it includes alpha, beta, and gamma attenuation measurements with count-rate modeling and reference-value comparison.
